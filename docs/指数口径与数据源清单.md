> 用途：给「指数观察」「宽基矩阵」两页提供**精确到接口/字段/单位**的数据口径，供 pipeline 任务落地。
> 编写时间：2026-10-14。**重要更正（同日复测）**：本机（WorkBuddy 沙箱）对 **东财 push2his / push2 已被反爬封锁**（请求返回空 body / 连接被掐），与项目既有约束「数据采集必须走云端」一致；腾讯 `qt.gtimg.cn`、新浪行情本机仍可达。因此**指数序列回补只能在 GitHub Actions 云端执行**（云端为不同 IP，不受本机封锁）。下文「实测」指当日曾短暂可达窗口或云端可用口径。

## 0. 先说结论：为什么图里大片是「—」和「样本不足」

**不是接口挂了，是指数序列没跟上最新交易日。**

| 现象 | 直接原因 |
|---|---|
| 「当日成交额」整列为 `—` | 指数序列 `data/series/index_amount_*.json` 最新点停在 **20261009**（部分停在 20260925/20260928），而页面「当日」= 最新交易日 **20261014** → 该日无点 → `amount=None` |
| 「历史百分位」为 `—`/「样本不足」 | `pctile` 由当日值算出，当日值为 None → `pctile=None` → 前端 `WidebaseView.vue:70` 判为「样本不足」 |
| 「本周平均」为 `—`，本月/年内平均有值 | `compute.avg_index_amount` 取区间内已有点；本周(10-12起)无点→None，本月/年内靠历史点仍有值 |
| 「微盘代理」却是正常的（0.46 亿 / 历史 0.1%） | 它由**当日全市场快照**现算（`compute.microcap_proxy_amount`），不依赖指数序列 → 快照通道正常它就正常 |

**上游根因**：云端 `update-data` 工作流自 2026-09-29 起持续失败，指数采集段未写入新点；本地也未做指数序列回补。
→ 修复 = 恢复云端每日增量 + 对缺失交易日做一次指数序列回补。
**注意**：本机对东财 push2his/push2 已被反爬封锁（与项目「数据采集走云端」约束一致），故回补**只能由 GitHub Actions 云端执行**，不可在本地跑东财源。腾讯实时行情本机可用但仅含当日、且不含北证50/中证2000，不足以做历史回补。

## 2. 指标口径（六列）

| 列名 | 定义 | 取数/公式 | 代码位置 |
|---|---|---|---|
| 当日成交额 | 该指数当日成交额 | 东财 kline `f57`（元）÷1e8；腾讯 `f37`（万元）÷1e4 | `index_mod.get_index_amount` |
| 今年涨跌幅(YTD) | 年初至今日涨跌幅 % | `最新收盘 / 上年末首个交易日收盘 − 1` | `index_mod.get_index_ytd_pct`（baostock） |
| 本周平均 | 本周内日均成交额 | 周一起（交易日历）至当日，序列均值 | `compute.avg_index_amount(..., "week")` |
| 本月平均 | 本月内日均成交额 | 每月1日起至当日，序列均值 | `compute.avg_index_amount(..., "month")` |
| 年内平均 | 年初至今日均成交额 | 1月1日起至当日，序列均值 | `compute.avg_index_amount(..., "year")` |
| 历史百分位 | 当日值在历史序列中的分位 | `(N − rank) / max(N−1,1) × 100`，1 位小数 | `compute.pctile` |
| 近一年排名 | 近 243 个交易日内降序名次 | `rank_1y` | `compute.write_series_merge` |

**单位约定**：成交额一律**亿元**；序列文件 `data/series/index_amount_{code}.json`，`points[].value` 即亿元。

## 3. 接口与字段规格（可直接照抄）

### 3.1 东财日线 K 线（主源，历史任意日期可回溯）

```
GET https://push2his.eastmoney.com/api/qt/stock/kline/get
    ?secid={市场}.{代码}          # 沪/中证=1，深=0，北证=0
    &fields1=f1,f2,f3,f4
    &fields2=f51,f52,f53,f54,f55,f56,f57
    &klt=101                      # 101=日线
    &fqt=0                        # 不复权
    &beg=YYYYMMDD&end=YYYYMMDD
```
返回 `data.klines[]`，逗号分隔：`f51 日期, f52 开, f53 收, f54 高, f55 低, f56 成交量(手), f57 成交额(元)`。
→ **成交额(亿) = float(f57) / 1e8**。

### 3.2 腾讯实时行情（备源/兜底，仅当日）

```
GET https://qt.gtimg.cn/q={腾讯code}      # 需 r.encoding = "gbk"
```
`~` 分隔：`f[1] 名称, f[2] 代码, f[3] 最新价, f[30] 时间戳YYYYMMDDHHMMSS, f[32] 涨跌幅, f[37] 成交额(万元), f[44] 流通市值(亿), f[45] 总市值(亿)`。
→ **成交额(亿) = float(f37) / 1e4**，且必须校验 `f[30][:8] == 目标交易日`。

### 3.3 限速（重要）

实测：**东财 push2his 短时间内高频请求会被临时限流，返回空 body**（复测已知可用的 `1.000001` 也会变空，冷却后恢复）。
→ 必须保留现有的 `common.retry` + `common.pace`（每次请求间 sleep），不要在循环里裸打。这也解释了云端偶发失败。
另：腾讯请求要 `session.trust_env = False`（避免本机代理干扰，代码已处理）。
