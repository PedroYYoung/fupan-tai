## 三、根因定位（实际代码路径）

```
build.py: build_one(date, dates)
  └─ spot_mod.get_spot(date)          # 参数 date 只用于腾讯通道的「成分清单」
       ├─ 通道1 ak.stock_zh_a_spot_em()      ← 无日期参数，返回当前会话
       ├─ 通道2 ef.stock.get_realtime_quotes ← 无日期参数，返回当前会话
       └─ 通道3 _tencent_spot(date)          ← 代码清单按日期，行情仍为当前会话

`spot_mod.get_spot()` 的 `date` 形参具有误导性：它只影响腾讯通道的代码清单，**不影响行情时点**。同理 `industry_mod.get_industry_daily()`（东财/同花顺板块快照）与 `compute.microcap_proxy_amount()` 也没有历史能力。

## 五、代码修复（`scripts/build.py`）

### 1. 唯一闸门

```python
def is_realtime_session_target(date, dates) -> bool:
    """目标日期是否为「最近一个已收盘交易日」——实时快照写入的唯一闸门"""
    return date == last_closed_trade_date(dates)
```

`build_one()` 开头：

```python
realtime = is_realtime_session_target(date, dates)
spot_df = spot_mod.get_spot(date) if realtime else None
```

历史日期下连抓取都不发生（沙箱实测 spot 调用 0 次），从源头消除「抓到今天的行情」的可能。

### 2. 三种处置状态（写入 `data_quality.spot_derived`）

| 状态             | 含义              | 行为                     |
| -------------- | --------------- | ---------------------- |
| `realtime`     | 目标日 = 最近已收盘交易日  | 与修复前完全一致，实时流程不受影响      |
| `carried_over` | 历史日期重建，旧快照已有该字段 | **原样沿用**（不重算、不清空、不改写）  |
| `unavailable`  | 历史日期且无可靠来源      | 置 `None` / 空列表，前端显示「—」 |

`_carried_spot_state()` 保证：已标记 `unavailable` 的快照**重跑也不会复活**错误数据。

### 3. 逐项保护（不改判定逻辑，只加闸门）

- 集中度 / 家数 / 分档：`spot_df is None` 时走 `_carried_spot_state`，不再调用 `compute.*`
- `micro_proxy` 行：历史日期不重算，取 `_carry_row(existing, "micro_proxy")`
- `industry`：历史日期**完全不调用** `get_industry_daily()`，沿用旧值
- 涨跌停：历史日期不传 `spot_df`（禁用快照兜底）；池接口失败时沿用旧值，**不写 0**
- `total_amount`：历史日期只接受指数口径；都不可用则沿用旧值（`_resolve_total_amount` 支持 `spot_df=None`）
- 序列写入：值为 `None` 时**跳过写入**（原来会把 `None`/0 写进序列）
- 不可用状态：`concentration` / `liquidity` 使用占位结构（空列表 + `None`），**绝不写 0**

### 4. 前端配套

| 文件                                                                         | 变更                                                              |
| -------------------------------------------------------------------------- | --------------------------------------------------------------- |
| `src/types.ts`                                                             | 相关字段改为 `number \| null`；新增 `DataQuality` / `SpotDerivedQuality` |
| `src/components/SpotDataNotice.vue`                                        | 新增：`spot_derived === 'unavailable'` 时显示「该日全市场快照不可用」提示条          |
| `TodayView / ConcentrationView / LiquidityView / EmotionView / ReportView` | 接入提示条；所有可空字段改用 `fmt/fmtNum`（`—`）；Top50 图表与表格空数据时显示空态            |
| `src/rules/engine.ts`                                                      | `limit_down` 为空时不再参与风险判定（避免 null 比较与假结论）                        |
